# Glosario

- **Skill:** capacidad reutilizable del agente.
- **Policy:** regla de comportamiento.
- **Workflow:** coordinación de pasos/capacidades.
- **Integration:** capacidad/herramienta externa.
- **Adapter:** implementación específica de runtime.
- **Verification:** evidencia ejecutable determinística.
- **Handoff:** estado vivo mínimo transferido ante un cambio real de contexto.
