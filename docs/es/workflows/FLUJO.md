# Flujo TRUSS v0.2

```text
Intent
  ↓
Discovery / Grill (si hace falta)
  ↓
Spec: proposal + behavior + design + tasks
  ↓
Vertical slice
  ├── BDD macro-loop
  └── TDD micro-loop
  ↓
Verification
  ↓
Code Review
  ↓
Alineación final / archive
```

`anchored`: la spec permanece como ancla y los descubrimientos se reconcilian explícitamente. `source`: los cambios de comportamiento vuelven primero a la spec.

Review cubre **Spec**, **Standards** y **Risk**. Se prefiere contexto fresco; handoff solo cuando cambia contexto o responsabilidad.
