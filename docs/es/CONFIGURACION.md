# Configuración de TRUSS

Esta página se mantiene como entrada de compatibilidad. La documentación de configuración actual está separada para distinguir referencia, efectos y ejemplos:

- [`configuration/reference.md`](configuration/reference.md): campos, tipos, defaults, valores, fallbacks y enforcement.
- [`configuration/effects.md`](configuration/effects.md): qué cambia en TRUSS cuando cambia cada valor.
- [`configuration/examples.md`](configuration/examples.md): configuraciones completas recomendadas.

OpenSpec es una base obligatoria de TRUSS y **no** se configura como integración opcional. Graphify sí es una capability configurable.
